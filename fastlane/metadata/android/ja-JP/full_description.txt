Omalauncher は、Omarchy の見た目を Android に持ち込む、キーボードで快適に操作できるホーム画面です。スマートフォンのアプリと並べて、完全な Arch Linux ARM システムを動かすこともできます。

テーマ
Tokyo Night、Catppuccin、Gruvbox、Nord、Rose Pine、Kanagawa、Everforest など、22 種類の Omarchy テーマから選べます。テーマはランチャー全体の配色を変え、専用の壁紙も付いてきます。壁紙はライブ壁紙としても使えます。

ホーム画面、ウィジェット、全画面ウィジェット
• ウィジェットと固定したアプリをグリッドに並べたページ
• 日付、天気、システム情報の組み込みウィジェット
• 全画面ウィジェット：漫画の 1 ページ、ターミナル、バウハウスのポスターのように、ページ全体をひとつの画面として描きます
• ウィジェット、全画面ウィジェット、小さなアプリやゲームが並ぶストア。どれもシンプルでオープンな言語で書かれていて、自分で編集できます
• すべての Android アプリを検索できるアプリドロワー

ARCH LINUX（任意）
ランチャーは Linux なしでも使えます。必要な場合は、Omalauncher が Arch Linux ARM をダウンロードし、proot で動かします。root 化は不要です。
• Linux アプリはそれぞれ独立したウィンドウで開き、最近使ったアプリの画面にも 1 枚ずつカードが並びます
• Omalauncher 自身が Wayland コンポジタなので、foot などのグラフィカルなアプリも動きます
• Arch Linux ARM と AUR のパッケージを検索してインストール
• ホーム画面でコマンドを実行するターミナルウィジェット
• 「ファイル」：Linux のホームフォルダと、選んだスマートフォンのフォルダを扱えるファイルマネージャー。コピー、移動、名前の変更、削除、開く、共有ができます
• テーマは Linux アプリにも適用されます

コーディングエージェント
Linux をインストールすると、ホーム画面下部のプロンプトバーから、Claude Code、Codex、Copilot、Grok、opencode などのコーディングエージェントにプロンプトを送れます。エージェントはターミナルで開きます。ウィジェットを作ってもらうこともできます。

VOICE
音声ボタンをタップして、コーディングエージェントに話しかけましょう。エージェントは声で答え、いま何をしているかを表示し、コマンドの実行やファイルの変更の前には確認を求めます。文字で入力したいときは、文字入力に切り替えて返答を読むこともできます。音声の認識は Android が行うため、Linux に届くのはテキストだけです。

キーボードショートカット
物理キーボードを接続すると、Super+T でターミナル、Super+D でドロワーを開き、Super+1〜9 でページを切り替え、Super+W でウィンドウを閉じられます。

言語
English、Bahasa Indonesia、Español、Português、Deutsch、简体中文、Русский、日本語。

プライバシー
アカウント不要、広告なし、トラッキングなし。Omalauncher がインターネットに接続するのは、テーマ、ウィジェット、天気、そして（選んだ場合に）Linux とそのパッケージをダウンロードするときだけです。

Omalauncher は独立したプロジェクトであり、Omarchy および Arch Linux とは提携していません。
